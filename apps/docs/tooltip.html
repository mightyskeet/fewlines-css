Tooltip

Short hint for an interface element: shown on hover or focus, dismissed with Escape or an outside click. Fully declarative — no runtime JS.

Semantic basis

The tooltip is a Popover API element (popover="hint") plus interest invokers (interestfor): in Chromium the browser shows it on hover/focus and hides it when interest is lost. Both features are progressive enhancements — in other engines the declarative popovertarget fallback opens the hint on click, and Escape / light dismiss stay native everywhere.

Canonical markup

<button class="ui-tooltip-trigger"
        popovertarget="tip-save"
        popovertargetaction="show"
        interestfor="tip-save"
        aria-describedby="tip-save">
  Save
</button>
<span class="ui-tooltip" id="tip-save" popover="hint">Saves your changes</span>

The trigger keeps its own styling (ui-button and friends); ui-tooltip-trigger only declares the anchor name. The hint is a sibling element, never a child of the trigger — child text would become part of the trigger's accessible name.

Example

Hover or focus the button: Saves your changes

Icon-only buttons are the main use case: View billing address, plan and payment method

The hint renders below the trigger, centered, and flips above automatically when there is no room (position-area + position-try-fallbacks, inside @supports). Several pairs on one page need scoped anchor names — wrap a pair in an element with anchor-scope: all.

Accessibility

  • aria-describedby is part of the canonical markup: it is the only description association in engines without interest invokers; where interest is supported the browser wires it natively.
  • WCAG 1.4.13 is native: Escape dismisses, the pointer can move onto the hint text, the hint stays visible until interest is lost or it is dismissed.
  • Keyboard: focus opens the hint (interest engines), Enter/Space opens it in the click fallback; Escape always closes. Focus is never trapped.
  • The tooltip role is implicit from popover="hint" — do not set it manually. Text uses the text/surface-raised pair, validated at the strict body APCA threshold (Lc 75) in both themes.

Do not

  • No JS for open/close — interestfor and popovertarget are declarative.
  • No interactive or long content inside the hint — that is a Popover; no custom placement attributes — the tooltip has one canonical placement with a native flip.
  • Do not use the title attribute — it is unstyleable and keyboard-inaccessible.
