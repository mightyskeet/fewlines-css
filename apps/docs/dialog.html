Dialog

Modal and non-modal window on top of the page: confirmations, forms, messages.

  • Overview
  • Button

  • Dialog
  • Popover

Native basis

<dialog> with top-layer behavior; showModal() / show() / close() called by the host application (core ships no runtime JS); ::backdrop; native Escape close; native focus trap; <form method="dialog"> closes without JS; :modal and dialog[open] for state styling.

Canonical markup

<button class="ui-button" type="button" onclick="dlg.showModal()">Open</button>

<dialog class="ui-dialog" id="dlg">
  <h2>Confirm</h2>
  <p>Are you sure?</p>
  <form method="dialog">
    <button class="ui-button" type="submit">Close</button>
  </form>
</dialog>

States and animation

  • Open — dialog[open]; modal — :modal; backdrop — ::backdrop.
  • Entry animation — @starting-style + transition-behavior: allow-discrete for display/overlay.
  • Without support the dialog simply appears (graceful degradation).

Accessibility

  • Native dialog role; accessible name from the heading or aria-labelledby.
  • Escape closes natively; focus returns to the trigger natively.
  • Focus trap is native — first focusable element or autofocus.

Do not

  • No div + position: fixed emulation — top-layer, focus trap and Escape are lost.
  • No JS for Escape/backdrop — native behavior.
  • Keep <form method="dialog"> for close buttons — the JS-free path.
  • No styling of dialog:not([open]) — natively display: none.
