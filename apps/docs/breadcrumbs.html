Breadcrumbs

The trail from the root to the current page on the native <nav> + <ol>: the landmark and the list semantics come with the elements, the current page is the native aria-current="page" state. Separators are drawn by the component. No JS.

Semantic basis

The component is the WAI-ARIA breadcrumbs pattern: a named navigation landmark, an ordered list of crumbs, links for the ancestors and aria-current="page" for the current page (announced by screen readers). The attribute may sit on the <li> (a plain-text crumb) or on the crumb's link — the CSS honors both. A stepper carries the progress of a process (Stepper), a breadcrumb carries the position in a hierarchy.

Canonical markup

<nav class="ui-breadcrumbs" aria-label="Breadcrumb">
  <ol role="list">
    <li><a href="/">Home</a></li>
    <li><a href="/library">Library</a></li>
    <li aria-current="page">Data</li>
  </ol>
</nav>

role="list" is insurance for the list-style: none quirk (the timeline precedent). aria-label on the <nav> is required — the landmark's accessible name. Separators are drawn by the component (li + li::before); the markup never contains them, and the slash carries an empty alternative text (content: '/' / ''), so assistive tech skips the punctuation.

States

  1. Home
  2. Library
  3. Data

Links keep the base link color; the underline is dropped at rest (the trail structure identifies the link) and returns on hover. The current crumb is full-contrast text — the native aria-current carries the semantics, not a color.

Collapsed levels

    The host collapses the middle crumbs into one <li> with a button[popovertarget] — a declarative trigger, zero JS; the hidden levels are listed in a menu popover (the canonical shell: light dismiss, Escape, anchor positioning below the trigger). The button must carry an aria-label — the visible glyph «…» is not a name. Collapsed is not an attribute variant: it is a documented composition with the Menu component.

    Current-item truncation

    1. Home
    2. Library
    3. very-long-name-of-the-current-page

    The current crumb is capped at --ui-breadcrumbs-max (default 40ch) and clips with a text-overflow ellipsis — a long page name cannot push the trail wide. The cap is a maximum, not a fixed width: in a narrow container the crumb shrinks further (the automatic flex minimum is zeroed by the clipping).

    Customization

    The separator and the toggle are text-muted (the registered fluent pair); the crumbs keep the base palette. Hosts re-theme through the local tokens — no variants, no classes: 

    .page-trail {
  --ui-breadcrumbs-max: 24ch;
  --ui-breadcrumbs-separator-color: var(--ui-color-border-strong);
  --ui-breadcrumbs-gap: var(--ui-space-xs);
}

    Accessibility

    • The navigation landmark, the list roles and the current-page state are native; aria-label on the <nav> is required.
    • The separator is generated content with an empty alternative text — it never enters the chain's accessible name.
    • Collapsed levels stay full-fledged links inside the menu popover; the trigger must carry an aria-label.
    • The text-muted pairs (separator, toggle) are registered in the APCA matrix as fluent pairs; links and the current crumb reuse existing pairs.

    Do not

    • No separator markup (<li> arrows, glyph characters) — the component draws them; duplicates break the rhythm.
    • No <div> chains instead of <nav> + <ol> — the landmark and the list semantics are the contract.
    • No aria-label-less nav or toggle; no state classes (.is-current and friends) — aria-current="page" only.
    • No display: none on the middle levels without a menu popover — the levels would be lost for navigation.
