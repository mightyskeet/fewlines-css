Progress

Operation progress indicator on the native <progress>: value model, progressbar role and the indeterminate state come with the element. Not interactive — no states, no JS.

Semantic basis

The component is the native progress indicator: the value/max model, the progressbar role and the determinate/indeterminate distinction belong to the element. A missing value attribute is the indeterminate state (:indeterminate) — the engine runs its own native motion, painted with the themed fill. The component only themes the paint: no keyframes, no state machine.

Canonical markup

<progress class="ui-progress" max="100" value="70" aria-label="Uploading"></progress>

The accessible name is mandatory — a <label> or aria-label (the same host contract as the table <caption>). The engine announces the percentage itself, so a textual «70%» next to the bar is not required.

Indeterminate

No value attribute — the native indeterminate state. The motion is engine-native; the component supplies only the themed colors.

Sizes

data-size="sm|lg"; default is md (no attribute). Density only: the bar thickness scales over the space scale (4 / 8 / 12 px), shape and tokens stay fixed.

Customization

The fill follows the brand family by default (the checked Switch model); the track is the de-emphasised soft surface with its stronger boundary (the neutral Alert model). Hosts re-theme through the local tokens — no variants, no classes: 

.upload-warning {
  --ui-progress-fill: var(--ui-color-attention);
}

Accessibility

  • The progressbar role is native; the accessible name is mandatory.
  • The fill/track pair is registered in the APCA matrix as a non-text pair (brand/surface-tint); the track boundary reuses the neutral Alert pair.
  • Reduced motion: the component adds no animation of its own.
  • Forced colors restore the native appearance — the system progress bar takes over with guaranteed system contrast.

Do not

  • No <div> bar instead of <progress> — the role, the value model and :indeterminate come with the element.
  • No unnamed progress bars — the accessible name is part of the contract.
  • No component keyframes for the fill — the engine animates the indeterminate state, determinate value jumps stay honest.
