Popover

Non-modal overlay: menus, tooltips, small panels. Light dismiss and Escape are native.

Native basis

Popover API: popover attribute; declarative trigger popovertarget; popovertargetaction="show|hide|toggle"; :popover-open; native light dismiss and Escape; native top-layer; implicit anchor from popovertarget (Chrome 133+, FF 147+, Safari 26+).

Canonical markup

<button class="ui-button ui-popover-trigger" type="button" popovertarget="p1">
  Options
</button>

<div class="ui-popover" id="p1" popover data-placement="block-end span-inline-end">
  <p>Popover content</p>
</div>

ui-popover-trigger on the trigger is optional — it enables anchor positioning (declares anchor-name). data-placement on the popover is optional — it mirrors the position-area value 1:1.

Live example

Anchor-positioned popover (fallback: centered). Click outside or Escape closes it.

Positioning

  • Default with anchor support: below the trigger (block-end center), flipped above on overflow; without anchor support: centered in the viewport (fixed).
  • Placement variants: data-placement on the popover mirrors the position-area value 1:1 — nine regions of the 3×3 grid plus eight edge-aligned span-* placements (all shown below).
  • Anchor contract: anchor name --ui-popover-anchor; no collision handling — fallbacks are the host's responsibility.

Placement

position-area places the popover in one of nine regions of the 3×3 grid built around the trigger (logical keywords; a lone center means centered over the trigger in both axes). The span-* keywords extend the region away from the trigger while the default alignment keeps the popover hugging it — flush with one edge of the trigger, the classic menu/tooltip alignment. Each cell scopes the anchor lookup with anchor-scope: all, so the shared anchor name pairs every popover with its own trigger. Verified in Chromium, Firefox and WebKit (compatibility notes).

Accessibility

  • Role and semantics come natively from the Popover API.
  • Light dismiss and Escape are native — no JS.
  • Focus is not trapped (non-modal) — native behavior.

Do not

  • No div + JS toggle emulation — light dismiss, Escape and top-layer are lost.
  • No position-visibility: anchor-valid/visible — outside the browser matrix.
  • No modal popover — for modality there is Dialog.
  • No physical span-left/right keywords — they are invalid; logical keywords only.
