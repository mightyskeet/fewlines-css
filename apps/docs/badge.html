Badge

Compact status label: statuses and counters next to headings, tabs and list items. Static inline element — no states, no JS.

Semantic basis

The platform has no native badge element, so the component is a static <span> and adds no JS: no role, no focus, no hover. The label text is the value itself; for ambiguous counters the host supplies an accessible name via aria-label.

Canonical markup

<span class="ui-badge">Beta</span>

Adjacent badges get a gap automatically (.ui-badge + .ui-badge). The label never wraps (white-space: nowrap) — badges are short labels by contract.

Variants

Default Neutral Info Success Warning Danger

data-variant="neutral|info|success|warning|danger" — soft tint surfaces (the feedback model, like Alert). Default (no attribute) is the brand pastel: brand-tint + brand — it follows a re-themed brand, the same brand-forward default as Button. neutral is the explicit gray member (surface-tint + text from the page gamut): the gray look never follows the brand. Pastel label pairs are tracked at the documented body minimum (Lc 60) since the -strong tones were removed; neutral sits at the strict body threshold (Lc 75). All pairs are validated by the APCA matrix in both themes.

Solid fill

Default Neutral Info Success Warning Danger

The same set with the boolean data-solid attribute: the fill flips to the button-default model — the bare family tone as the fill with on-* text. Bare data-solid (no variant) = the default brand family — the high-contrast gray pill in the default theme that follows the brand once re-themed. neutral + solid is the brand-independent inverted gray (text fill + surface label). The warning tone doubles as its own solid fill: white on the lighter 500 step fails the APCA body threshold, on 600 it passes (Lc 87.8).

Sizes

Small Medium Large

data-size="sm|lg"; default is md (no attribute) — the standard pill shown in the Variants block above. Geometry scales, the label size stays: sm 16px, md 20px, lg 28px.

Counters

Inbox 3

A bare number is rarely self-explanatory for assistive tech — the host adds aria-label when the count alone is ambiguous.

Accessibility

  • Badge is a generic inline element: no interactive role, not focusable, no states.
  • Color is never the only carrier of meaning (WCAG 1.4.1) — the label text states the status; variant styling reinforces it.
  • The 0.75rem label size relies on pairs validated at the strict body-role APCA threshold, not on the smaller-text allowances; pastel label pairs are tracked at the documented body minimum (Lc 60).

Do not

  • No interactive badges — a <button> or <a> styled as ui-badge is out of contract; actions belong to Button.
  • No variant classes — variants are expressed only via data-variant.
  • No multi-line pills — white-space: nowrap is part of the contract; multi-line labels belong in Alert or plain text.
