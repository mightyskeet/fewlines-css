Field

Text input with label, description and native validation.

Native basis

<input>, <textarea>, <select>; implicit <label> via nesting; native validation (required, type="email", pattern); native states including :user-invalid (:user-valid matches but is intentionally not styled).

Canonical markup

<label class="ui-field">
  <span class="ui-field-label">Email</span>
  <input class="ui-input" type="email" required placeholder="you@example.com" />
  <span class="ui-field-description">We never share your email.</span>
</label>

Controls

Controls: ui-input, ui-textarea, ui-select; the ui-field wrapper is shared.

Sizes

data-size="sm|lg" (default — md) on the control. The height scale matches Button (1.75 / 2.25 / 2.75rem), so inputs, selects and buttons align in one row. Single-line controls pin block-size — WebKit renders select taller when only min-block-size is set.

Textarea autosize

Progressive enhancement (field-sizing: content): the textarea grows with content, bounded by min-block-size: 3lh and max-block-size: 50vh. Without field-sizing support the size comes from rows. Opt-out: data-field-sizing="fixed".

Validation states

The red border appears only after user interaction (:user-invalid); the valid state is intentionally not styled — the platform paints nothing there either. Never style bare :invalid. Host-rendered error text uses ui-field-error bound via aria-describedby.

Read-only and file

Read-only fields keep the value selectable and copyable — the subtle surface signals the fixed value (distinct from :disabled). The file button (::file-selector-button) is styled with tokens: subtle surface, hairline divider, full field height.

Accessibility

  • Implicit label via nesting — accessible name without for/id.
  • aria-describedby for hints and errors.
  • Placeholder is not a label — never remove <label>.

Do not

  • No styling of :invalid without :user-.
  • No JS validation replacing native validation.
  • No div inside label (label is an inline container).
  • No size classes — sizes are only data-size on the control.
  • No host fonts larger than the size scale on single-line controls — use data-size="lg".
