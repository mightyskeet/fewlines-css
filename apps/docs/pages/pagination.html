Pagination

Page sequence navigation on the native <nav> with links: navigation is native, the page state lives in the URL, the current page is the native aria-current="page" state. No JS.

Semantic basis

The component is the WAI-ARIA pagination pattern: a <nav aria-label="Pagination"> landmark with a <ul> of links. Every entry is a real <a href> — the navigation works without JS, and the current page is a non-link <li aria-current="page"> (a page does not link to itself). Not a breadcrumb trail and not a stepper: those carry hierarchy and process progress.

Canonical markup

<nav class="ui-pagination" aria-label="Pagination">
  <ul role="list">
    <li><a href="?page=1" rel="prev" aria-label="Previous page">‹</a></li>
    <li><a href="?page=1">1</a></li>
    <li aria-current="page">2</li>
    <li><a href="?page=3">3</a></li>
    <li aria-hidden="true">…</li>
    <li><a href="?page=12">12</a></li>
    <li><a href="?page=3" rel="next" aria-label="Next page">›</a></li>
  </ul>
</nav>

Edge glyph links must carry aria-label — ‹/› are not accessible names. rel="prev"/"next" is part of the canon.

The current page is the only filled pill and the only non-link — the state is not color alone. Hover fills the pill (pointer-gated), press shifts it 1px, focus takes the base ring.

Disabled edges

An unavailable edge (no previous page on page 1) is a native <button type="button" disabled> — the same pill geometry as the links (the row stays steady), muted, skipped by the keyboard natively. The Button twin pattern: <a> navigates, <button disabled> marks the off state. The host may omit the <li> entirely instead. Skipped ranges collapse into <li aria-hidden="true">…</li> — screen readers skip the punctuation, the page sequence stays the story.

Customization

No variants — hosts re-theme through the local tokens. Centering the row on the page is host styling (justify-content on the <ul>): 

.compact-pager {
  --ui-pagination-size: 1.5rem;
  --ui-pagination-accent: var(--ui-color-attention);
  --ui-pagination-on-accent: var(--ui-color-on-attention);
}

Accessibility

  • The landmark has a name (aria-label="Pagination" is mandatory); the list roles are native.
  • The current page is the native aria-current="page" state and is not in the tab order.
  • Edge glyph links carry aria-label; the ellipsis is aria-hidden.
  • The pill pairs (text, hover, on-brand, text-muted) are registered in the APCA matrix — no new pairs.
  • Forced colors repaint the pills from the system palette natively.

Do not

  • No links on the current page — aria-current="page" sits on the <li>, the entry stays out of the tab order.
  • No <button> or href="#" stubs — entries are real links.
  • No state classes (.is-current and friends) — the native attribute only.
  • No edge glyph links without aria-label.
