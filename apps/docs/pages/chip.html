Chip

Compact interactive control with the Badge look: filters, tag actions, small add/remove actions in dense toolbars. Native button/link semantics — no JS.

Semantic basis

A chip is an action, so the element is a real <button> (or <a> for navigation): hover, press, focus and disabled come from the platform, the same state model as Button. A static label is Badge, not Chip — do not style a <span> as ui-chip.

Canonical markup

<button class="ui-chip" type="button">Label</button>

Adjacent chips get a gap automatically (.ui-chip + .ui-chip). The label never wraps (white-space: nowrap) — chips are short labels by contract. Icons auto-size to 1rem and never intercept the pointer; icon-only chips require aria-label.

Variants

data-variant="neutral|attention" — the Badge pastel set (soft tint surfaces, like Alert). Default (no attribute) is the brand pastel: brand-tint + brand. Hover fills the same family one step toward its contrast pole (brand-tint-hover, the generic hover fill, attention-tint-hover).

Solid fill

The boolean data-solid flips the fill to the button-default model — the bare family tone with on-* text. neutral + solid is the brand-independent inverted gray (text fill + surface label); its hover walks toward the surface (inverse-hover).

Sizes

data-size="sm|lg"; default is md (no attribute) — the pill shown in the Variants block above. Geometry scales, the label size stays: sm 24px, md 28px, lg 32px — the smallest chip already meets the WCAG 2.5.8 target size.

Filters

The typical chip patterns: filter toggles and removable tags. The remove icon is aria-hidden="true"; the accessible name comes from the label text plus the host-supplied aria-label when the icon alone carries meaning.

Disabled

Link chip

Native :disabled covers buttons; links use aria-disabled="true" (a link cannot be disabled natively — the host also gates the navigation).

Accessibility

  • Chip text is the accessible name; icon-only chips require aria-label, the icon gets aria-hidden="true".
  • :focus-visible ring from the base layer — do not override.
  • Color is never the only carrier of meaning (WCAG 1.4.1) — the label states the action; variant styling reinforces it.
  • All label pairs are validated by the APCA matrix in both themes; pastel pairs sit at the documented body minimum (Lc 60).

Do not

  • No <div class="ui-chip"> — only <button> or <a>; a non-interactive label belongs to Badge.
  • No JS for hover/active/disabled states — they are native.
  • No variant classes — variants are expressed only via data-variant.
  • No multi-line pills — white-space: nowrap is part of the contract.
