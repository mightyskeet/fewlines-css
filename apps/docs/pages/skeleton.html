Skeleton

Placeholder for content that has not loaded yet: text lines, an avatar, a card block. Static decorative element — no states, no JS.

Semantic basis

The platform has no placeholder element, so the component is an empty static <span> (the Badge model): no role, no focus, no states. A skeleton carries no information of its own — the “this area is loading” signal belongs to the host, which marks the loading region with aria-busy="true" and removes it when the real content lands.

Canonical markup

<span class="ui-skeleton" style="inline-size: 12rem"></span>

Geometry is the host's: the placeholder borrows the geometry of the content it stands in for. The defaults fit the most common case — a text line: full-width block, one line tall (block-size: 1em follows the surrounding font-size, so the layout does not shift when the real text lands).

Text lines

A stack of lines stands in for a paragraph. The line heights and the gaps between the blocks are host layout — the component paints only the surface and the sweep.

Avatar + lines

Any shape is host geometry plus the radius token — a full radius makes the avatar circle. No data-shape attribute: the shape is expressed by geometry, not variants.

Card block

Large blocks stand in for cards or media. The shimmer is always on — a skeleton without motion is just a gray block; reduced motion parks it on the calm surface.

Customization

Local tokens: --ui-skeleton-surface (default surface-tint), --ui-skeleton-highlight (the band color, a calm mix towards the page text), and the shared --ui-shimmer-duration (default 1.5s) and --ui-shimmer-lean (default 30deg) — the same motion knobs as Progress, --ui-skeleton-radius (default --ui-radius-md). Hosts override with semantic tokens, not classes; data-variant does not exist — the placeholder is decorative and needs no color semantics.

Accessibility

  • An empty element carries no text, so it never enters the accessibility tree: no role, not focusable, no states.
  • The loading signal is the host's aria-busy="true" on the region — removed together with the placeholders when content arrives.
  • Decorative paint: WCAG 1.4.11 does not apply — the placeholder conveys no information, no APCA pairs are registered.
  • Reduced motion silences the sweep — the placeholder stays a calm static surface.
  • Forced colors strip the paint; the empty box keeps reserving the layout space.

Do not

  • No content imitation (gray text, icons) inside the placeholder — it would enter the accessibility tree; the skeleton is decoration.
  • No geometry animation (size pulse) — the only motion is the highlight sweep across the surface.
  • No roles (status, progressbar) on the placeholder — the loading signal is aria-busy on the host region.
