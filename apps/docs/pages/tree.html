Tree

A hierarchy of content on the native nested <ul>: reply chains, outlines, file lists. Branch collapsing is the native <details> disclosure — no JS, no ARIA tree roles.

Semantic basis

The component is the native nested list: the list/listitem roles and the hierarchy come with the elements. A branch node is a native <details> — the disclosure state, the keyboard behavior (Enter/Space on the summary) and the marker are the platform's. A static (always-open) branch is a plain nested list. The component adds the rail-and-elbow vocabulary — the guide lines — opt-in over the base layer. The interactive treeview control (ARIA tree semantics) is out of scope without a JS layer.

Canonical markup

<ul class="ui-tree" role="list">
  <li>package.json</li>
  <li>
    <details open>
      <summary>src</summary>
      <ul role="list">
        <li>button.css</li>
      </ul>
    </details>
  </li>
</ul>

role="list" is insurance for the list-style: none quirk — on every list. Node content is host-authored: leaf nodes are any host elements; the component only zeroes the outermost margins of the node's first and last children. The summary keeps the native disclosure marker.

The rails are 2px borders on zero-width pseudos — they survive forced colors (a background strip would not). Each node's elbow exits at the node's first-line center ((1lh + line-width) / 2); the children rail hangs one line width left of the parent's text edge and drops from the parent's first-line center. The last branch terminates with the rounded elbow (└─); a passing rail runs straight through the junction and the branch curves off it (├─). All positioning is logical — the layout mirrors itself in RTL.

Customization

The rail is the border token — decorative (the list semantics carry the structure). Hosts re-theme through the local tokens — no variants, no classes: 

.release-tree {
  --ui-tree-indent: var(--ui-space-lg);
  --ui-tree-rail-color: var(--ui-color-brand);
}

Accessibility

  • The list roles are native; the hierarchy is native nesting. Branch disclosure is native (details/summary): Enter/Space toggle, the accessible name is the summary content, aria-expanded is not needed.
  • The rails are decorative by construction — the structure is in the nesting (WCAG 1.4.1). The rail reuses the divider policy (decorative line, no APCA pair).
  • Forced colors repaint the rails (borders) and the marker natively.
  • Collapsing is instant: no motion, reduced-motion handling not required.

Do not

  • No anchor positioning for the connectors: a repeated anchor name resolves to the first element in tree order — every reply would attach to the first comment; in nested DOM the borders need no anchors at all.
  • No <div> grid instead of nested <ul> — the list semantics are the contract.
  • No ARIA tree/treeitem roles — the disclosure tree covers display.
  • No collapse animation via ::details-content — its overflow: hidden clips the rail drop segment.
  • No variant classes — hosts re-theme through the local tokens.
