Tabs

Switching panels on the native <a>: each tab is a link to itself, so the active state is the native :target and the URL fragment, the Back button and deep links come with the element. No JS, no state classes, no ARIA role substitution.

Semantic basis

Tabs are in-page navigation: links that reveal a section. The component does not fake the ARIA tab pattern — role="tab" with aria-selected would promise arrow-key navigation that pure CSS cannot deliver. The links stay links; assistive technology reads a set of links and a visible section. Hosts that need the ARIA state can add it in their own JS layer.

Canonical markup

<div class="ui-tabs">
  <a class="ui-tab" id="release-overview" href="#release-overview">Overview</a>
  <section class="ui-tabs-panel" aria-labelledby="release-overview">
    <h3>Overview</h3>
    <p>…</p>
  </section>
  <a class="ui-tab" id="release-specs" href="#release-specs">Specs</a>
  <section class="ui-tabs-panel" aria-labelledby="release-specs">
    <h3>Specs</h3>
    <p>…</p>
  </section>
</div>

The link's id equals its href — the link is its own fragment target, so activating a tab makes it :target. The panel is the link's next sibling: the adjacency is the pairing mechanism (:target + panel), no per-tab CSS. With no tab fragment in the URL the group's first tab is open — the default state via :has().

Accessibility

  • The links announce as links; activation with Enter; hidden panels are out of the accessibility tree and the focus order.
  • Each panel carries aria-labelledby pointing at its tab link — the panel's accessible name is the tab label, without JS.
  • Which tab is active is not announced natively (the ARIA state needs JS); hosts may add aria-current in their own layer.
  • The APCA pairs are existing registrations: text-muted/text on surface and the border-strong indicator (non-text).

Do not

  • No role="tab"/aria-selected without JS — the roles promise a keyboard model (arrow keys, roving tabindex) that the links do not implement.
  • No wrappers between a link and its panel — the adjacency is the switching mechanism.
  • No scroll-target-group on the bar — the scrollspy highlight would disagree with the open panel.
  • Tab state follows the URL: a fragment that points elsewhere on the page returns every group to its first tab. That is the documented behavior, not a bug.
