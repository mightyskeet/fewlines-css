Choice

Checkbox and radio on the native inputs: custom box and dot, an SVG-masked check mark, native states and keyboard. No JS, no extra markup.

Native basis

<input type="checkbox"> and <input type="radio"> — native toggling and selection, native keyboard (Space / arrows), native form participation and states (:checked, :disabled, :user-invalid). The check mark is an SVG path applied as a mask-image on the control itself: the shape belongs to the SVG, the color to the token. It fades in on check — a stroke-draw needs an inline SVG in the markup, which the component avoids.

Canonical markup

<label class="ui-choice-field">
  <input class="ui-checkbox" type="checkbox" />
  <span class="ui-choice-label">Email notifications</span>
</label>

<label class="ui-choice-field">
  <input class="ui-radio" type="radio" name="speed" value="standard" />
  <span class="ui-choice-label">Standard</span>
</label>

The wrapper is an implicit label — clicking the text toggles the control. The label span is required (the accessible name). The check mark carries no markup: it is an SVG path applied as a mask-image on the control itself. Radios of one group share the name.

States

Checked = the brand fill with the on-brand mark (the Switch model). The dash for :indeterminate is host-set through el.indeterminate = true — no HTML attribute exists; it is host JS, core carries none.

Required

The attention border appears only after interaction (:user-invalid — the same intent gate as Field). The native validation bubble carries the signal before that.

Beta options

The group is ui-fieldset + legend: native group semantics, the accessible name and native group disabling (fieldset[disabled]). Members placed adjacent get the gaps automatically. See Fieldset.

Accessibility

  • Semantics, name and keyboard are native; the radio group under a legend replaces repeated labels.
  • The state is carried by the mark shape (check / dash / dot), not by color alone (WCAG 1.4.1).
  • No new APCA pairs: on-brand/brand (the solid fill), border/border-strong frames, attention invalid border.
  • Focus ring comes from the base layer. Reduced motion disables the fade.
  • Forced colors: Highlight checked fill, HighlightText mark — the state survives background stripping.

Do not

  • No <div>/<span> instead of <input> — native semantics and keyboard are the contract.
  • No removing the label span — the accessible name is required.
  • No state classes (.is-checked) and no styling :invalid without :user-.
  • No setting indeterminate from HTML — host sets the property via JS.
  • No JS emulation of group disabling — fieldset[disabled] is native.
