Colors

The color system: base tokens plus formulas. Every semantic token is derived from a handful of OKLCH numbers per family — no color ramps.

Model: bases + formulas

A palette is one OKLCH seed per family per theme — Neutral, Brand, Link and Attention — and light and dark are tuned independently. Formulas derive every semantic token from the seeds: surfaces, text, borders, fills, on-* contrast poles, hover states and tints. The sliders edit the theme you are looking at — use the theme toggle to switch.

Besides the seeds, the formulas expose a few named steps — how far hover fills walk toward the contrast pole, how far muted text fades toward the surface, how strongly borders bite. Steps are scalar parameters of the derivation, not colors: change a seed's hue and every shade follows it. Absolute per-token color overrides stay a host-level concern (--ui-color-* set directly) — they are what breaks that seed linkage, so the widget does not offer them.

Fills use a polarity branch: a seed lightness up to 0.70 produces a vivid fill with a white contrast pole, a lighter seed produces a saturated pastel with a near-black pole — the branch jumps the APCA dead zone. The branch runs per theme on that theme's seed.

Components consume only these names (theme notes); the swatches in the sections below show the values currently in effect — drag a family's sliders and watch them follow.

Defaults are calibrated and APCA-validated in CI. Beyond the calibrated defaults the formulas make no guarantees — contrast is the host's responsibility, which is why every family section below carries a live pass/fail table for the current theme. The Hover step slider sets how far a hover fill walks toward the contrast pole: a smaller step is calmer and keeps more contrast headroom.

Neutral

The seed is the page surface, per theme. Text anchors its own lightness and takes the seed's chroma and hue; raised surfaces step toward the text pole; borders, hover fills and the focus ring derive from the same two poles. The Muted text, Border and Strong border steps tune those mixes — the strong boundary step also drives the focus ring.

Surfaces

The gray page gamut — every neutral look of a component (badge without a variant, secondary/outline/ghost buttons, table rows, fields) is built from exactly these tokens, so it never follows a re-themed brand family. Dark-theme hover takes the full raised step: a half-step reads as invisible on the wide dark surface ramp.

Brand

The action family — default buttons, kbd, the checked Switch. Each theme's fill IS that theme's seed (the default is the inverted gray); the polarity branch picks the contrast pole per theme — white for a vivid seed, near-black for a pastel one. Raise the chroma for a brand look — hover and the tint follow automatically.

The table also tracks the Neutral sliders — the pairs share a surface background.

Link

Hyperlink text on the page and raised surfaces; the selection tint derives from the same seed.
