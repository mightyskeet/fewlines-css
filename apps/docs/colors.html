Colors

Live theming playground: pick semantic token colors and the whole documentation restyles at once. Choices persist in localStorage and apply on every docs page.

How it works

Each picker writes an inline override on :root as light-dark(light, dark), so the theme toggle keeps working. Inline styles win over core.css. Reset removes all overrides; Copy CSS gives the same overrides as a host-ready snippet.

Defaults are APCA-validated in the repository. Once you override tokens, contrast is your responsibility — check readability in both themes before shipping (the planned formula system adds a live pass/fail table here, see docs/plans/2026-10-26-color-derivation.md).
