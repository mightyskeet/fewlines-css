Button

Action element: submit forms, open dialogs, run commands.

Native basis

<button type="button|submit|reset"> — primary element; <a href> for navigation styled as a button. Native states: :hover, :active, :disabled, :focus-visible. No JS classes required.

Canonical markup

<button class="ui-button" type="button">Label</button>

Variants

data-variant="primary|destructive"; default is secondary (no attribute).

Sizes

data-size="sm|lg"; default is md (no attribute).

States

Link as button

Disabled via :disabled (excluded from tab order natively); aria-disabled="true" for <a>. Focus ring comes from the base layer (--ui-focus-ring) — do not override.

Accessibility

  • Button text is the accessible name; icon-only buttons require aria-label.
  • APCA pairs: on-accent/accent-surface, text/surface-raised, on-danger/danger-surface.

Do not

  • No <div class="ui-button"> — only <button> or <a>.
  • No JS for hover/active/disabled states.
  • Do not override outline — the focus ring is system-wide.
