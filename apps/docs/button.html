Button

Action element: submit forms, open dialogs, run commands.

Native basis

<button type="button|submit|reset"> — the brand-colored element; <a href> for navigation styled as a button. Native states: :hover, :active, :disabled, :focus-visible. No JS classes required.

Canonical markup

<button class="ui-button" type="button">Label</button>

Variants

Link

data-variant="secondary|outline|ghost|attention|link"; default is default (no attribute). The default variant is the brand family, inverted polarity by default: a dark fill in the light theme, near-white in the dark (--ui-color-brand; a brand look is one override away). secondary is the brand pastel (brand-tint + brand) — it follows the brand like the default. Filled variants carry no border — the fill is the surface.

Sizes

data-size="xs|sm|lg"; default is md (no attribute). Small sizes also step the font down to --ui-font-size-sm.

Icon

data-size="icon-xs|icon-sm|icon|icon-lg" — square buttons for icon-only actions. Icons auto-size to 1rem. An icon-only button requires aria-label; the icon itself is aria-hidden="true".

States and modes

Link as button

Disabled via :disabled (excluded from tab order natively); aria-disabled="true" for <a>. Focus ring comes from the base layer (--ui-focus-ring) — do not override. Loading keeps the label in flow (color: transparent — the width never changes) and overlays a CSS ring spinner on the button's own ::after (aria-busy="true"); reduced motion parks the ring, the state stays visible.

Accessibility

  • Button text is the accessible name; icon-only buttons require aria-label.
  • APCA pairs: on-brand/brand, on-brand/brand-hover, brand/brand-tint, brand/brand-tint-hover, on-attention/attention, text on surfaces (outline, ghost, link variants).

Do not

  • No <div class="ui-button"> — only <button> or <a>.
  • No JS for hover/active/disabled states.
  • Do not override outline — the focus ring is system-wide.
  • Do not ship an icon-only button without aria-label.
