Fieldset

Grouping of related form controls: frame with the legend cut, the group's accessible name and native group-level disabling. No JS.

Native basis

<fieldset>/<legend> — the group semantics and the accessible name are native; fieldset[disabled] natively disables every descendant control. The layout is the UA flow: spacing between members comes from the stack rules (.ui-field + *, .ui-switch-field + .ui-switch-field).

Canonical markup

<fieldset class="ui-fieldset">
  <legend class="ui-fieldset-legend">Shipping address</legend>
  <label class="ui-field">
    <span class="ui-field-label">Street</span>
    <input class="ui-input" type="text" placeholder="Main st. 1" />
  </label>
</fieldset>

The legend is required — it is the group's accessible name and the native border split.

Beta options

disabled on the fieldset is the native group switch: every descendant control is disabled, the legend mutes. No per-control attributes needed.

Accessibility

  • The group role and its name are native (legend); for radio groups the legend replaces repeated labels.
  • Disabled state: the native propagation is the behavior; the muted legend is only the visual signal, controls dim themselves.
  • No new APCA pairs: text/surface and text-muted/surface.
  • Forced colors repaint the border with the system color automatically.

Do not

  • No <div> instead of <fieldset> — the native group is the contract.
  • No removing the legend — the accessible name is required.
  • No grid/flex on the fieldset — the legend border split belongs to the engine's special layout.
  • No JS emulation of group disabling — fieldset[disabled] is native.
  • Not a decorative frame for content without controls — for sections there are headings, for breaks there is Divider.
