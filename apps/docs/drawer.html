Drawer

Non-modal panel sliding in from the viewport edge: filters, mobile menus, carts.

Native basis

Popover API — popover on the panel gives top-layer, light dismiss and native Escape; popovertarget / popovertargetaction="hide" open and close it declaratively (core ships no runtime JS); ::backdrop is the native pseudo-element (host may style it as a scrim); autofocus inside the popover moves focus in natively; @starting-style + transition-behavior: allow-discrete animate the slide-in.

Canonical markup

<button class="ui-button" popovertarget="cart">Cart</button>

<aside class="ui-drawer" id="cart" popover data-variant="drawer-end">
  <h2>Cart</h2>
  <p>…content…</p>
  <button class="ui-button" popovertarget="cart"
          popovertargetaction="hide" autofocus>Close</button>
</aside>

The panel element is the host's semantic choice (aside, nav, form, section); the heading or aria-label provides the accessible name.

Live example

Cart

Non-modal edge panel. The page stays interactive; Escape or an outside click closes it. Focus moved here natively via autofocus.

Menu

Default variant (drawer-start): pinned to the logical inline-start edge, correct under RTL.

Variants: data-variant="drawer-start" (default) | "drawer-end" — logical inline edges. Geometry: full viewport height, width min(24rem, 100%), radius on the inner edge only.

States and animation

  • Open — :popover-open; closed — native display: none.
  • Slide-in — @starting-style + transition-behavior: allow-discrete for translate/opacity/display/overlay.
  • Reduced motion disables the animation; without support the panel appears as is.

Accessibility

  • Semantics and role come from the host element; the popover API adds none.
  • Focus moves into the panel natively (autofocus) and is not trapped — the drawer is non-modal by design; focus return to the trigger is the host's job.
  • Escape and outside click close natively; the outside click also reaches the page underneath.
  • A scrim look is a host decision: style ::backdrop and lock scroll via body:has(#id:popover-open) — semantics stay non-modal; a blocking panel is Dialog.

Do not

  • No div + position: fixed + JS toggle emulation — top-layer, light dismiss and Escape are lost.
  • No JS for open/close — popovertarget is declarative.
  • No modal drawer, no focus trap — blocking panels are Dialog.
  • No data-block/data-inline/anchor positioning — that is Popover; Drawer pins to the viewport edge.
